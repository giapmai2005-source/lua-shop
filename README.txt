LỤA. — NGỌC GIÁP / NHÓM 7
Mở index.html trong trình duyệt hoặc dùng VS Code Live Server.
Home: index.html. Danh mục: all-products.html, top.html, bottom.html, dress.html.
CSS: style.css. Dữ liệu sản phẩm, lọc và Quick add: app.js.
Ảnh mẫu: images/. Ảnh từ images.unsplash.com (ID nguồn ở đầu app.js), chỉ minh họa; thay bằng ảnh đúng sản phẩm trước khi nộp.
Bố cục mobile dựa trên wireframe được cung cấp; desktop và màu là đề xuất, chưa đối chiếu mockup chính thức.
Giỏ hàng: localStorage key lua_cart_v1, JSON array [{id,name,category,price,image,sizes,colors,size,color,quantity}]. Giá là số VND. Anh Tú dùng cùng key để tích hợp cart/checkout. Giỏ phân biệt id+size+color.
Khung chung được dựng tạm vì nhóm chưa có code; phối hợp với Mạnh trước khi ghép.
Có xem giỏ và xóa dòng để thử Quick add, chưa có checkout, tài khoản hay gửi email.
Chạy offline: HTML/CSS/JS và ảnh đã có sẵn. Font Google cần Internet, khi offline tự dùng Georgia/Arial. localStorage có thể bị trình duyệt hạn chế khi mở file trực tiếp; dùng Live Server nếu cần ghép giỏ qua nhiều trang.
Đưa lên GitHub Pages: đẩy toàn bộ nội dung thư mục này vào repo nhóm, chọn Settings > Pages và nhánh chứa index.html.
Đưa lên Netlify: tải cả thư mục chứa index.html bằng chức năng deploy thủ công của tài khoản nhóm.
Bản đăng trên ChatGPT Sites là bản xem riêng, không thay thế link GitHub Pages/Netlify dùng nộp bài.
